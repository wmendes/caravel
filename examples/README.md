# Starters

Small, complete things to build on, for HackMeridian teams and anyone trying Caravel. Each one runs end to end with `caravel` alone, on your machine.

| Starter | What it shows |
|---|---|
| [agent-payments](agent-payments/) | Agents paying each other small amounts on a lane, each payment confirmed in a block, money in and out through Stellar |

More are coming: a lane behind a passkey wallet, and a lane with an oracle (Caravel Perps already is one: `caravel init perps`).
