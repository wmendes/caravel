# The lane file

The lane file reference now lives on the docs site, with the rest of Caravel's documentation: **https://caravel-docs.vercel.app/reference/lane-file**

Its pages are written in this repository, under [`docs-site/docs/reference/lane-file/`](../docs-site/docs/reference/lane-file/):

| [Deployment](https://caravel-docs.vercel.app/reference/lane-file/deployment) | `[env.<name>]`: network, admin, token, validators, sequencer, relayer, host |
| [Hosts](https://caravel-docs.vercel.app/reference/lane-file/hosts) | Several hosts, validators run elsewhere, several lanes on one host |
| [Accounts and tokens](https://caravel-docs.vercel.app/reference/lane-file/accounts-and-tokens) | Declared accounts and tokens |
| [Contracts](https://caravel-docs.vercel.app/reference/lane-file/contracts) | Declared contracts |
| [Modules](https://caravel-docs.vercel.app/reference/lane-file/modules) | Local modules |
| [Composition and vars](https://caravel-docs.vercel.app/reference/lane-file/composition) | `include`, `extends`, vars, locals, `for_each` |
| [Expressions](https://caravel-docs.vercel.app/reference/lane-file/expressions) | Expressions and attributes |
| [Outputs](https://caravel-docs.vercel.app/reference/lane-file/outputs) | Outputs and the web app's config |
| [Resources and targets](https://caravel-docs.vercel.app/reference/lane-file/resources) | Addresses, `--target`, `--replace`, saved plans |
