Infrastructure as code for Stellar appchains

Declare a lane.
Plan it.
Apply it.

Caravel turns one lane file into an appchain that settles to Stellar in the token you choose. plan shows every change on Stellar and on your host before it's made, apply makes it, and destroy winds the lane down to an exit proof for every account.

Your rules

Every rule is a line.
Every change gets a plan.

On Stellar, every app shares the network's fees and rules. A lane sets its own in one file. Pick what you'd change: plan says what apply would do, before it does it.

# lane.toml  [[env.e2e.validators]]- name = "3"- key = "validator-3"+ name = "4"+ key = "validator-4"

Run a lane on your machine.

A Payments lane on a local Stellar network: install the CLI, write the lane file with caravel init, apply it, and use the lane. You need Rust 1.93, the Stellar CLI 28.1.0, Node.js 22 and Docker.

# install from a clone, into ~/.caravel
./scripts/install.sh
export PATH="$HOME/.caravel/bin:$PATH"

# a lane, its users, its end
caravel init payments my-lane && cd my-lane
caravel apply
caravel account create alice --amount 100
caravel account create bob --amount 10
caravel deposit alice 50 && caravel deposit bob 5
caravel tx --from alice transfer --to @bob --amount 5
caravel withdraw alice 10
caravel destroy --yes
caravel escape alice
