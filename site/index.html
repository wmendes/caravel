Open source, for teams building on Stellar

For Stellar apps that need their own rules.

Like an exchange that matches every 0.5 sa payment network for members onlya game economy with 200 ms turnsagents that pay per request in 200 ms

Caravel runs your app as a lane: an appchain with its own block time, fees, members, limits and validators, declared in one file. Your users' money stays on Stellar, in the token you choose.

Declare it. Plan it.
Apply it.

  1. Declare

    One lane.toml holds the lane's rules and every place it runs: your laptop, your servers, testnet.

  2. Plan

    caravel plan lists every step on Stellar and on your hosts before anything is sent, down to the settlement contract's address.

  3. Apply

    caravel apply deploys the contract, starts the sequencer, validators and relayer, and the lane starts checkpointing to Stellar. Run it again and nothing changes.

Every rule is a line.
Every change gets a plan.

Change a rule and run plan. Some changes are a restart, some a signer rotation on Stellar, and some the contract won't allow. Pick one to see what plan says.

# lane.toml  [[env.e2e.validators]]- name = "3"- key = "validator-3"+ name = "4"+ key = "validator-4"

$ caravel apply lane.toml --env e2e

Run a lane in five minutes.

Install the CLI and caravel apply brings up a lane on a local Stellar network, its nodes in containers. Deposit, transfer, withdraw, then take it down. The same file deploys to your servers.

You need Docker. The installer brings the rest, for Linux and macOS.
